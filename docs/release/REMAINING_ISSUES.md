## 2. Non-Blocking Optimization & Backlog Items

### Priority: Low / Post-Launch Enhancement

| ID | Category | Description | Impact | Recommended Solution |
| :--- | :--- | :--- | :--- | :--- |
| **OPT-01** | **Bundle Size Optimization** | The `WishesShowcase` bundle chunk is currently ~1,149 KB uncompressed (~231 KB gzipped) because it bundles the complete 500+ Diwali & Dhanteras wishes dataset into a single chunk. | Non-blocking. The chunk is already code-split via `React.lazy()` and only loads when navigating to `/wishes`. | In a future release sprint, split the wishes database by festival (`wishes/diwali.json` and `wishes/dhanteras.json`) using dynamic `import()` so clients only load the active festival's wishes. |
| **OPT-02** | **Image Thumbnail Optimization** | Greeting template thumbnails currently rely on SVG vector previews rendered on canvas thumbnails. | Non-blocking. Rendering is client-side and completes within 300ms on first paint. | Pre-generate WebP thumbnail sprites or low-resolution vector placeholders for even faster gallery scrolling on low-end 2G/3G connections. |
| **OPT-03** | **Service Worker Offline Caching** | The service worker `public/sw.js` currently caches core app shells and assets. | Non-blocking. The site functions completely online and handles standard browser caching. | Expand `sw.js` to provide offline access for personalized cards previously generated by the user in IndexedDB. |
| **OPT-04** | **PWA Install Prompt Analytics** | Custom "Install FestiveWala App" banner tracks standard button clicks. | Non-blocking. Native browser install heuristics function normally. | Add dedicated GA4 custom event tracking (`pwa_install_accepted`, `pwa_install_dismissed`) once user traffic scales. |
| **OPT-05** | **Greeting Studio Lab Performance Optimization** | Greeting Studio scores 43 in lab Lighthouse due to initial rendering of 100 canvas templates and MediaPipe vision bundle. | Non-blocking. Editor interaction runs smoothly once loaded; desktop users experience 60fps canvas manipulation. | Lazy load MediaPipe vision models only when user enters photo framing mode, and virtualize template card list. |
| **OPT-06** | **Physical Android Hardware Field Testing** | Testing was performed via Playwright Chromium mobile emulation with touch events; no physical device was connected. | Non-blocking. Emulated touch gestures and viewport constraints verified. | Perform on-device touch validation on physical Samsung/Pixel devices once lab hardware is accessible. |

## 3. Verified Resolved Issues During Audit Lifecycle

| ID | Issue Discovered | Root Cause | Resolution Applied | Verification Status |
| :--- | :--- | :--- | :--- | :--- |
| **FIX-01** | Mobile photo dragging occurred during page scrolling | Canvas touch handlers intercepted vertical pointer movements without gesture intent filtering. | Added `touch-action: pan-y` default, explicit `[ ✋ Reposition Photo ]` mode toggle, and 5px threshold filter. | **VERIFIED FIXED** via `tests/mobile-touch-gesture.spec.ts` (12-step test passed). |
| **FIX-02** | Mobile typing and Backspace lag in Greeting Details | Synchronous dispatch pushed undo snapshots and triggered canvas re-renders on every keystroke. | Decoupled present state (synchronous) from undo history (400ms debounce) and canvas redraw (60ms rAF). | **VERIFIED FIXED** (Keystroke overhead: 30.57ms, Backspace: 27.11ms). |
| **FIX-03** | TypeScript interface mismatch on `GiftIdea` | `festivalId` and `nameHinglish` properties were missing on `GiftIdea` interface. | Added optional `festivalId?: string` and `nameHinglish?: string` in `src/data/gifts/giftsData.ts`. | **VERIFIED FIXED** (`tsc -b` passes with 0 errors). |
| **FIX-04** | TrilingualFAQSection prop type errors in `DhanterasGuideArticle` | Required language props `festivalNameEn`, `festivalNameHi`, and `initialLang` were omitted. | Passed correct props to `TrilingualFAQSection`. | **VERIFIED FIXED** (Build and SSR schema validation pass). |
| **FIX-05** | Dhanteras missing in Festival Directory (`/festivals`) | Dhanteras was present in detailed routes but missing in `FESTIVALS_DATA`. | Added Dhanteras to `src/data/festivals.ts` and `FestivalsPage.tsx` spotlight filters. | **VERIFIED FIXED** (Appears on `/festivals` with search & season filter). |
